Guía de estilo

Puedes escribir contenido con la sintaxis de Markdown de GitHub.

consejo

Usamos un archivo .prettierrc para aplicar estilos estándar con el formateador de código "Prettier". Si usas VS Code, puedes instalar Prettier desde https://marketplace.visualstudio.com/items?itemName=esbenp.prettier-vscode

Asegúrate de formatear tu trabajo antes de abrir una PR.

Enlaces​

Soy un enlace de referencia

Puedes usar números para definir enlaces de referencia

O déjalo vacío y usa el propio texto del enlace.

Las URL, con o sin corchetes angulares, se convierten automáticamente en enlaces. http://www.example.com/ o <http://www.example.com/> y a veces example.com (pero no en GitHub, por ejemplo).

Algo de texto para mostrar que los enlaces de referencia pueden ir más adelante.

Tablas​

Puedes usar dos puntos para alinear las columnas.

Las tablassongeniales
la col 3 estáalineada a la derecha$1600
la col 2 estácentrada$12

Debe haber al menos 3 guiones separando cada celda del encabezado. Las barras verticales exteriores (|) son opcionales, y no hace falta que el Markdown sin procesar quede bien alineado. También puedes usar Markdown en línea.

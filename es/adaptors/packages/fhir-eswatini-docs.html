addToBundle​

addToBundle(resources, [name]) ⇒

Add a resource to a bundle on state, using the name as the key (or bundle by default). The resource will be upserted (via PUT). A new bundle will be generated if one does not already exist.

Returns: Operation

ParamTypeDescription
resourcesobject/arrayA resource or array of resources to add to the bundle
[name]stringA name (key) for this bundle on state (defaults to bundle)

This operation writes the following keys to state:

State KeyDescription
bundlethe updated bundle

Example: Add a new patient resource to the default bundle

addToBundle(b.patient($.patientDetails))

mapValues​

mapValues(url, [mappings]) ⇒

Set value mappings against a value-set. Pass the URL of the valueset you want to provide mappings for. For each mapping, the key is the input string, and the value is either a code string or a full object value to map

Returns: Operation

ParamTypeDescription
urlstringThe URL of the value set you are providing mappings for
[mappings]objectobject of mappings

Example: Create a custom mapping for Patient.inkhundla

mapValues('http://172.209.216.154:3447/fhir/ValueSet/SzTinkhundlaVS', {
 // Maps input value "lobamba" to mapping code "3"
 lobamba: '3',
});
